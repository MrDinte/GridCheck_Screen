GridCheck

Install GridCheck on the screen

A wall display for Sigenergy solar and battery systems, for the Waveshare ESP32-S3-Touch-LCD-7B (7", 1024×600). It reads your inverter over your own Wi-Fi; no cloud, no account.

1. Connect the board

  1. Plug a USB-C cable into the board's port labelled UART, and the other end into this computer. Use a cable that carries data, not a charge-only one.
  2. Use Chrome or Edge on a computer (not a phone). Firefox and Safari can't talk to USB devices.

2. Install

This browser can't install firmware. Open this page in Chrome or Edge on a computer. This page must be opened over https (as it is on GitHub Pages).
  1. Pick the board in the list that pops up (often called USB Single Serial or CH343, or a COM port) and press Connect.
  2. Choose Install. New screen: tick Erase device. Already running GridCheck: leave it unticked so your Wi-Fi and settings are kept. It takes about a minute.
  3. When it says it's done, press the board's RESET button.

Board not in the list? Try the other USB-C port or another cable. If it still doesn't show, hold BOOT, tap RESET, let go of BOOT, then press Install again. On older Windows you may need the CH343 USB driver from Waveshare's site.

3. Set it up from your phone

  1. The screen shows Not set up yet. On your phone, join the Wi-Fi called GridCheck-Setup.
  2. A setup page opens (if not, go to http://192.168.4.1). Choose your home Wi-Fi, type its password and the inverter's IP address, then Save.
  3. The screen restarts and joins your Wi-Fi. Settings are then at the address shown at the bottom of the screen.

No inverter connection yet? Tick Show demo data instead on the setup page to check the screen works.

4. Updates

From version 0.5.0 the screen updates over Wi-Fi, so you only need USB once. When a new version is out, the screen's Settings & info page says so: tap Firmware, then tap again to install. Or press Install update on the phone settings page. It never installs on its own.

Every update is digitally signed, and the screen refuses anything that isn't signed with GridCheck's key. Set a PIN on the phone settings page so only you can change settings or start an update.
